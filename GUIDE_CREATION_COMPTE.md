# 📋 Guide Complet - Création de Compte Bancaire EGA BANK

## 🎯 Informations Requises (Comme dans une Vraie Banque)

Lors de la création d'un compte bancaire chez EGA BANK, nous collectons les informations suivantes :

---

## 1️⃣ Informations de Base

### Type de Compte
- **💳 Compte Courant** : Pour vos opérations quotidiennes
  - Découvert autorisé (ex: 10 000 FCFA)
  - Carte bancaire
  - Chéquier
  
- **💎 Compte Épargne** : Pour économiser
  - Taux d'intérêt (ex: 3.5% par an)
  - Pas de découvert
  - Rémunération mensuelle

### Client
- Sélection du client existant (après validation KYC)

---

## 2️⃣ Informations Professionnelles (KYC Bancaire)

**Exemples** :
- Enseignant

**Pourquoi ?** Pour évaluer votre profil financier et vous proposer des services adaptés.

## 📄 Relevé Bancaire PDF

### Qu'est-ce qu'un Relevé ?
Un document officiel qui récapitule :
- 📅 Toutes vos transactions sur une période
- 💰 Solde initial et final
- 📊 Détails de chaque opération
- 🏦 Informations du compte et du client

### Comment Imprimer votre Relevé ?

**Via l'Interface Web** :
1. Connectez-vous à votre espace client
2. Allez sur "Mes Comptes"
3. Cliquez sur le compte souhaité
4. Cliquez sur "⋮" (menu) → "Relevé PDF"
5. Le PDF se télécharge automatiquement

## ✅ Checklist de Création de Compte

### Avant de Créer le Compte
- [ ] Client validé (KYC personnel effectué)
- [ ] Pièce d'identité vérifiée
- [ ] Adresse confirmée
- [ ] Email et téléphone vérifiés

### Informations à Collecter
- [ ] Type de compte choisi
- [ ] Profession renseignée
- [ ] Revenus mensuels estimés
- [ ] Employeur indiqué
- [ ] Objectif du compte défini
- [ ] Agence de rattachement sélectionnée
- [ ] Contact d'urgence fourni
- [ ] Téléphone d'urgence vérifié

### Paramètres du Compte
- [ ] Découvert défini (si compte courant)
- [ ] Taux d'intérêt configuré (si compte épargne)
- [ ] Solde initial = 0 FCFA

### Après Création
- [ ] IBAN généré automatiquement
- [ ] Email de confirmation envoyé
- [ ] Carte bancaire commandée (optionnel)
- [ ] Chéquier commandé (optionnel)
- [ ] RIB (Relevé d'Identité Bancaire) généré

---

## 🚀 Prochaines Étapes Après Création

### Jour 1 : Compte Créé
- ✅ Solde : 0 FCFA
- ✅ IBAN attribué
- ✅ Compte actif

### Jour 2-3 : Premier Dépôt
- Le client peut faire son premier dépôt
- Méthodes : Espèces, virement, chèque

### Semaine 1 : Activation Complète
- Carte bancaire reçue (si commandée)
- Code PIN reçu séparément
- Chéquier reçu (si commandé)

### Mois 1 : Utilisation Normale
- Dépôts et retraits
- Virements
- Consultation du solde
- Téléchargement de relevés
